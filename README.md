# NEXUS — landing-tolemisov

Лендинг компьютерного клуба NEXUS. Тема проекта: **компьютерный клуб**.

## Лаба 2
- Семантические `header`, `nav`, `main`, `section`, `article`, `footer`.
- Адаптив: 375px и 1280px, промежуточная ширина 768px.
- SEO: `title`, `description`, `keywords`, структурированная семантика.
- Accessibility: `label` для полей, `aria-label`, видимый focus.
- Форма бронирования с HTML5-валидацией.

## Лаба 3 — почему Modern CSS
Я выбрал современный чистый CSS без фреймворка, потому что для небольшого лендинга он даёт полный контроль над структурой и внешним видом. В проекте используются CSS-переменные в `:root`, поэтому основные цвета и размеры можно менять из одного места. Для адаптивных размеров заголовков используется `clamp()`. CSS nesting и container queries позволяют писать более современную и локальную стилизацию, однако в этом лендинге основной layout построен обычным Grid/Flexbox, чтобы код оставался понятным. По сравнению с Tailwind здесь меньше служебных классов в HTML, а по сравнению с Bootstrap нет зависимости от готовых компонентов. Для такого компактного сайта чистый CSS оказался самым прозрачным вариантом.
